# 效果动画检查与待审核项

检查日期：2026-10-25。

本轮按 `cards/effects/` 中实际使用的效果操作，检查引擎事件、后端参与者视图、正式游玩页和公共动画组件。这里区分规则执行与视觉表现：下列待审核项是展示方式的选择，不代表对应规则没有实现。动画依据引擎已提交的事件播放，不重新抽牌、洗牌或执行效果。

## 本轮已补充

回合结束的弃牌、补牌、洗牌也接入有序移动数据，防止同一次动作被公开日志和移动记录重复播放。已有的疾病生成／转交、战斗摧毁、怪物离场、宝藏展示、陷阱原位触发和移除继续使用原动画。

新增 `MatchView.card_motion` 仅包含观看者自己获准知道的实例移动，不含其他玩家的隐藏抽牌名单、洗牌顺序或效果解释器内部状态。公开大厅事件只补充阶层和位置。刷新、中断、减少动态效果偏好仍收束到服务器最终快照。

## 审核意见与落实

以下保留本轮原建议及你的审核意见。六项已按意见接入；实现情况如下。自动化检查验证事件、权限、状态与动画调度，实际画面仍由你在现有服务中验收。

| 项目 | 已落实的行为 |
| --- | --- |
| 临时翻开 | 玩家牌区新增临时“翻开” Tab，仅在有牌时显示；合法候选可在原位高亮、点击响应。处理完毕后消失。摧毁、弃牌、取回都使用事件中的实际实例。 |
| 跨玩家 | 借入、归还、其他玩家的抽弃牌使用对应头像收发；未知牌使用牌背。动画开始关闭浏览窗。其他玩家的洗牌也以牌背播放，不传真实顺序。 |
| 连续检定 | 前 6 张正常播放；此后相邻的未命中揭牌与弃牌合并为最多 8 张的快速小批次。命中、摧毁、替代和洗牌是合并边界。“跳过动画”仅收束到已提交的最终状态，不提交任何规则选择。完整移动流不再截取末尾 160 条。 |
| 附着／囚禁 | 宿主左下角展示缩略叠牌和数量，点击可浏览、空格 检视，并区分附着类型。有武器时合并展示；仍可在组内操作武器。附着和释放使用宿主缩略牌位置作为飞牌端点。 |
| 地下城偷看／交换／混洗 | 授权者的偷看结果进入临时 Tab；公开交换同时播放两张牌的路线。顶部混洗显示少量牌背交错，不展示真实随机顺序。 |
| 视窗定位 | 飞牌临时切到来源所在公共 Tab，将来源移入可视范围；结束或跳过后恢复此前的 Tab、平移和缩放。 |

数据路径：引擎提交事件 → 后端按观看权限生成 `card_motion`／`table_motion` → match 页统一时间线 → 共享卡牌动画组件。动画本身不执行游戏规则。历史撤回／跳转会清理旧动画和弹窗，直接恢复对应状态，不重播过去的事件。

以下为实施前的提案原文及你的审核意见，保留供追溯。

### 1. 翻开若干张牌并等待选择时，暂存在哪里展示？

例：哈鲁利化身者 TS-0368、预言灵药 TS-0280、斥候 TS-0224、净化仪式 TS-0262。

这些牌可能先翻开多张牌，再等玩家选择、排序或摧毁。它们暂时离开了原牌堆，也还不属于手牌或弃牌堆。当前普通的连续翻开后移走可以播放飞牌，但跨越一次玩家响应的临时揭牌，尚没有统一的展示位置。

**建议：**在原抽牌堆位置提供一个临时“已翻开”浏览视图，点击其中合法卡牌完成选择；卡牌随后从该视图飞往最终区域。只向有权查看的玩家展示牌面，不重新引入占空间的效果候选区。另一种方案是使用现有旁置 Tab 展示临时揭牌，但这需要明确区分“规则上的旁置”和“仅展示中的翻开”。

审核意见：在玩家手牌区的位置增加一个临时tab，用来放这些翻开需要临时处理的卡牌。

### 2. 其他玩家的抽牌、弃牌，以及借牌如何呈现？

例：海德拉 TS-0463、沙鲁林秘祭师 TS-0404、托林角斗士 TS-0327、潜伏者幽影 TS-0452、混沌卷轴 TS-0298。

本轮通用牌区飞牌针对自己的牌区；其他玩家的数量和可见卡牌仍同步刷新，公开摧毁等已有动画保持不变。借牌、归还和重新分配涉及跨玩家来源，当前没有统一的跨玩家路线。

**建议：**以右侧对应玩家头像作为其他玩家的收发位置，借入的公开卡牌从头像飞入自己的手牌，归还飞回原主头像。对旁观者，公开转移显示正面，未知的抽牌或随机分配显示牌背；不在动画中泄露对方抽牌顺序。若打开了该玩家的牌组浏览窗，先关闭它，再播放同一路线，避免两套落点。

审核意见：按建议来。

### 3. 大量连续检定时，动画是否加速？

例：滚石陷阱 TS-0689、龙之颚 TS-0693，以及海德拉 TS-0463 的持续翻牌。

这些效果可能连续翻开很多张牌，并在中途洗回弃牌堆。按每张完整播放会拖长等待。当前投影保留最近的有限条展示事件，长事件链可能只能恢复部分动画，最终牌组仍以权威快照为准；本轮不宣称这类长链已经完整逐牌演示。

**建议：**前 6 张按普通速度，随后未命中牌快速成批飞往弃牌堆，命中的牌仍单独展示并执行摧毁／替代动画；洗牌保留。可另加“跳过动画”按钮，仅结束展示，不跳过任何规则响应。也可选择始终逐张播放。

审核意见：按建议来。

### 4. 附着、囚禁的卡牌放在哪里？

例：圣典秘祭师 TS-0422、希德之灵 TS-0425、囚笼 TS-0684、翡翠之龙 TS-0704、蓝宝石龙 TS-0705。

这些是 `attach_card`／`release_attachment` 关系，不应全部当作普通旁置，更不能误记为武器装备。当前还缺少统一的附着牌落点及释放动画。

**建议：**在宿主卡左下角叠放小卡，避开右上角状态标记；多张时显示张数，点击浏览。附着牌从来源飞到宿主，释放时从宿主飞往规则指定区域。若宿主已有武器缩略牌，则合并为可展开的附着牌组，并区分武器和其他附着关系。

审核意见：按建议来。

### 5. 偷看地下城、交换或洗混顶部牌时如何展示？

例：变形术 TS-0263、托利斯预视者 TS-0454、斯林长弓手 TS-0362、村庄暴民 TS-0226、假老兵 TS-0526。

普通大厅换位已补充；这些牌还涉及大厅与手牌／临时揭牌区交换，或将若干牌混入地下城顶部，不能直接套用玩家弃牌堆洗回动画。

**建议：**公开交换的两张牌交叉飞往对应位置；私人偷看的候选只对有权查看的玩家显示。混洗时从地下城堆顶部提起少量牌背，和返回牌一起短暂交错，再收回原牌堆，不展示随机后的真实顺序。临时揭牌的摆放采用第 1 项确定的方案。

审核意见：按建议来。

### 6. 动画来源不在当前可视范围时，要不要切换视窗？

例：地下城回合通过幻影之刃 TS-0265 从村庄供应取得武器；供应堆或目标卡因平移、缩放而在视窗外。

当前若能取得来源坐标就使用该坐标；完全无法取得有效来源坐标时直接同步最终牌区，不伪造来源。因而此类效果还不能保证每次都能看见完整飞牌。

**建议：**为动画临时切到来源所在 Tab，并把来源移入可视范围；动画结束后恢复此前 Tab 和视窗位置。另一种更安静的方案是保持视窗不动，改用视窗边缘作为飞入点，并短暂显示来源名称。

审核意见：为动画临时切到来源所在 Tab，并把来源移入可视范围；动画结束后恢复此前 Tab 和视窗位置。
