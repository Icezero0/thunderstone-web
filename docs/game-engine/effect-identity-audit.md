# 效果身份判断审计

本清单于 2026-10-25 重新检查全部 467 条可执行能力、206 条持续规则，以及 `engine/src/` 的过滤器、购买、复制、战斗、供应和设置代码。扫描嵌套查询、条件、计数、排除条件、装备者条件及持续加成参数，区分目标身份和正常的效果来源绑定。

英雄、怪物、疾病、雷霆之石、村庄身份已使用标签；「给予疾病」属于能力标签，不参与怪物族群匹配。本轮补齐民兵及宝藏的遗漏，修正 26 条能力／持续规则中的 44 处过滤条件；另修正复制民兵的原子校验、额外购买候选和购买次数扣除三处运行时判断。没有新增卡牌标签或修改 CSV／SQLite；基础民兵与精锐民兵原本均有「民兵」标签。

## 已确认：同名副本与“其他”的范围

2026-10-25 用户确认以下三条的范围。猛犸按卡牌定义排除全部猛犸；生命值光环则按实例 ID 只排除自身，同名副本可以互相加成。

| 卡牌 | 卡文 | 确认范围 | 实现 |
| --- | --- | --- | --- |
| TS-0615 猛犸 A01 | 全局：地下城中存在猛犸时，无法攻击其他腐化德鲁伊。 | 排除所有猛犸，不同实例也不互相保护。 | `hall_target_restriction` 保留卡牌定义比较，其他腐化德鲁伊仍按标签识别。 |
| TS-0680 终末骑士 A03 | 其他怪物获得生命值 +1。 | 只排除自身，其他终末骑士可获得加成；多个来源分别叠加。 | `monsterHealth()` 的生命光环按来源实例 ID 排除。 |
| TS-0679 死亡哨卫 A03 | 当死亡哨卫停留在阶层 0 时，其他所有怪物获得 +1 生命值。 | 跨地下城作用，包括其他死亡哨卫；每张位于阶层 0 的来源各提供 +1，自身不获得自己的加成。 | 所有大厅统一收集来源，提供者必须位于阶层 0；按实例 ID 排除自身，离开阶层 0 后停止提供加成。 |

对应代码为 `battle/combat.ts` 的 `hall_target_restriction` 和 `monsterHealth()` 中的 `hall_aura` 来源排除。生命值计算优先使用明确的目标实例；省略时，只采用定义匹配的上下文目标，否则从大厅查找，避免把其他怪物的实例误用为目标。浏览器预览与权威战斗使用同一实现。

`engine/tests/hall-aura-identity.test.mjs` 覆盖全部猛犸的例外、两张及三张终末骑士互相加成、跨地下城的死亡哨卫、非阶层 0 的来源失效、不同光环叠加、实例专属附着牌，以及浏览器预览与实际战斗生命值一致性。

## 本轮验证

`engine/tests/militia-tags.test.mjs` 使用真实卡牌目录，覆盖精锐民兵与基础民兵混合计数、购买价格和次数、短矛装备条件、持续加成、摧毁／弃牌费用、能力复制、对手展示、战斗后摧毁、非民兵排除、疾病数量、突破、回合末及宝藏标签。每次指令比较 Node 与浏览器引擎结果；针对目标选择使用多个合法候选，验证普通英雄不会混入民兵候选。另有全量发布规则检查，防止再次引入未说明的精确目标 ID。

## 已转换的怪物判断

- 38 条能力中的 56 个 `subcategory=怪物` 谓词已改为 `tag=怪物`；生成脚本同步更新。
- `semantic_type=monster`、怪物金币归零、同族加成的手牌筛选、最少怪物数量计分，以及怪物战斗目标，均检查怪物标签。
- 怪物下方附着疾病等动作校验同样检查标签；守护者的特殊阶层、战败去向及卡文移动限制另行处理。
- 阶层 0 守护者可以被返回地下城牌堆，不参加普通阶层换位；返回使用所属地下城的真实牌堆，也不触发普通阶层补位。死亡哨卫、黑暗勇士仍须被击败才可从大厅离场，该限制不妨碍将手牌中的对应战利品换入大厅。直接击败守护者正常给予经验，击败末日之心仍触发终局。
- `subcategory=怪物` 作为通用 DSL 的精确分类过滤能力仍可使用，但当前发布效果不再用它表示通用怪物身份。

## 已转换的疾病与雷霆之石判断

- 26 条能力中的 45 个疾病分类判断改为“疾病”标签；84 条能力中的 160 个排除疾病判断改为 `tags_none=[疾病]`。正向与排除判断可能出现在同一能力中，不可直接相加。
- 疾病攻击惩罚、攻击转魔法时排除疾病、疾病附着校验、移交后的获得替代流程，以及摧毁疾病时回无限供应，均按疾病标签识别。
- 亵渎守卫的雷石返回效果、雷石计数与计分平局优先、大厅雷石终局检测，以及开局跳过雷石，均按“雷霆之石”标签识别。
- 末日之心同时具有“怪物”“雷霆之石”标签，计入两类数量及相关计分（包括恐惧之石的其他雷石加分）；它仍优先执行守护者及末日之心的专属突破／终局流程。
- 乌布里克的头盔／护甲／臂甲已有“宝藏”标签；本轮将高地士兵的宝藏效果筛选也改为该标签。
