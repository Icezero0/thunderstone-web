# 地下城、战斗与终局

本文件展开《飞龙尖塔》规则书第 9～20、24 页的标准地下城流程。它描述基础时点和状态变化；单张卡牌覆盖通则时，由 [能力运行时](06-ability-runtime.md) 提供有来源的修改。

## 1. 一次地下城行动的结算顺序

| 顺序 | 子阶段 | 主要处理 |
| ---: | --- | --- |
| 1 | `DUNGEON_REVEAL` | 展示整手牌，结算强制展示/战利品效果 |
| 2 | `DUNGEON_PREPARE` | 依玩家选择使用地下城能力、分配武器；准备阶段的摧毁立即生效 |
| 3 | `TARGET_DECLARED` | 选择大厅里一只可攻击的怪物或守护者，记录其实例与阶层 |
| 4 | `BATTLE_RESOLVE` | 计算攻击、光照和限制；结算该目标战斗效果并重新计算，判定胜负 |
| 5 | `BATTLE_REWARD` | 失败怪物按规则退回；胜利取得怪物、经验，结算凯旋 |
| 6 | `HALL_REFILL` | 大厅低阶层补位、翻开新牌；依序结算陷阱、宝藏等 |
| 7 | `BREACH_AND_END_CHECK` | 结算移动至阶层 1 的突破及即时终局条件 |
| 8 | `TURN_WILL_END` → `TURN_CLEANUP` | 处理剩余延迟效果、弃牌、抽下一手牌；已确认终局时改入 `SETTLING` |

规则书第 24 页把大厅补充后的陷阱放在突破之前。进入阶层 1 的雷霆之石使标准对局立即结束；它的判定不能被普通回合末抽牌拖后。某张卡牌若改变上述顺序，需要明确的替代或延迟规则。

## 2. 准备、装备与目标

进入地下城时必须展示手牌。可选地下城能力由玩家决定是否、按什么顺序使用；强制效果和手牌战利品必须结算。准备阶段被摧毁的牌立即离场，之后不能再贡献印刷数值、能力或作其他费用。新抽到的牌加入当前手牌和本次计算。

每名英雄通常最多装备一件武器，每件武器只能装备给一名英雄。武器重量 `<=` 英雄当前力量才合法；未装备武器没有收益。力量变化使已装备武器超重时，该武器脱落并立即失去收益。某些卡牌会允许额外装备或记录“本场战斗曾装备”，因此分别保存当前装备关系和历史事实。法术、物品和战利品可以在没有英雄时提供收益。

准备结束后必须选一个目标，即使队伍预计无法取胜。规则书区分“不能攻击”和“不能击败”：禁止使用某牌收益后攻击的特性可能使目标不合法；“需要魔法攻击”则可能允许宣告但导致无法击败。目标是否合法由当前使用的牌和怪物限制判断，不能只比较生命值。被禁止参与攻击的英雄仍在队伍中，可能被战斗效果选中。

## 3. 攻击计算与解释账本

引擎需保存各来源的贡献和处理顺序，而非只有一个攻击总数。标准计算可描述为：

1. 分别收集普通攻击和魔法攻击的牌面值、装备收益、地下城效果与持续修正。对免疫、受限英雄、禁止使用的牌逐项筛掉或调整来源。
2. 结算疾病等负修正。疾病卡的 `-1` 在应用前选择当时至少有 `+1` 的一种合法攻击类型；普通与魔法攻击不能因一张疾病同时各减 1。某一来源或分项的值可以为负。
3. 应用规则要求的最终翻倍、减半及向下取整。规则书明确：总攻击翻倍在计入疾病等攻击修正后、**光照惩罚之前**处理。怪物的法术免疫、魔法攻击免疫、只能用魔法攻击等限制并不等价，必须分别表达。
4. 对普通阶层计算未被抵消的光照惩罚：`max(0, 阶层基础惩罚 + 有效怪物/环境修正 - 有效光照)`。每 1 点未抵消惩罚使攻击减少 2；过量光照不加攻击，光照惩罚不能使最终攻击低于 0。阶层 0 守护者战斗的光照惩罚恒为 0。不能减少光照惩罚等特性可替代这个标准式。
5. 在目标战斗效果改变力量、装备、攻击或生命值后重新求值，并应用目标的击败条件。最终有效攻击 `>=` 当前有效生命值且所有强制条件满足，才判为击败。

例如阶层 2 怪物在没有其他修正时基础光照惩罚为 2；若队伍有效光照为 1，剩余惩罚为 1，最终攻击减少 2。此类中间值应出现在可审计的 `CalculationTrace` 中：来源实例、原值、修正原因、处理时点、有效/被免疫状态、最后合计。客户端展示战斗说明可以读取这份账本，不自行重算。

## 4. 战斗效果与摧毁时点

被攻击怪物的战斗效果无论胜负都执行。准备阶段已经生效的地下城效果先于怪物战斗效果；战斗效果可能降低力量、给予疾病、阻止某英雄攻击或标记摧毁。战斗中获得的疾病进入弃牌堆，不影响当前战斗。

没有明确要求立即执行的战斗摧毁先标记，牌仍参与本次战斗，计算胜负后才实际执行。卡文明确写出“立即摧毁”或要求支付摧毁费用时，当场执行，离场牌不再贡献之后的战斗数值。若摧毁被替代为弃牌，仍视为成功支付费用。

“摧毁改为弃牌”保存在英雄实例的 `flags.turn_buffs`，持续至当前回合结束。守护者之刃在装备时给予对应英雄该状态；盛宴、神馔在发动时给予手中所有英雄。取得状态后，英雄离开手牌、武器脱落或来源被移除都不撤销状态；期间的立即摧毁、战后摧毁、回合末摧毁均由弃牌替代，替代不消耗状态。处理后移除待摧毁标记，回合结束再清除保护，避免影响之后的回合。它属于原英雄实例，升级后新实例不会继承。

力量下降若使武器不再可装备，则武器收益立即失效，即使对应英雄仍参与到战斗结束。英雄在战斗中力量曾降至 `0` 时，保留 `PENDING_DESTRUCTION_AT_TURN_END` 标记，后来恢复力量也不撤销；这由 `BASE_STRENGTH_ZERO_DESTRUCTION` 系统规则一次处理。回合末执行摧毁时保护仍有效，之后才到期。`TS-0717-A02`、`TS-0718-A02` 只是该规则的提示引用，不重复摧毁。

要分别记录 `PENDING_AFTER_BATTLE` 和 `PENDING_AT_TURN_END`，并为每个实例去重。特殊卡牌可能明确改变延迟时点；运行时必须按具体能力的触发阶段执行。

## 5. 胜负、怪物去向与凯旋

胜利时，被击败的怪物归当前玩家，进入其弃牌堆，玩家取得该怪物的 `defeat_xp_reward`。胜利后可结算英雄或其他牌的凯旋效果；没有攻击或不能参与攻击的英雄，不能贡献自身凯旋能力。若凯旋允许购买，按规则书第 13 页使用本场仍在场的已展示卡牌金币值；多个凯旋购买各自可使用整手的完整金币值，**不套用村庄多次购买共用金币预算的规则**。

失败时，普通怪物回到地下城牌堆底部。具有“必须被击败才离开”特性的怪物以及守护者不会因为失败离场；仍要结算适用的战斗效果。怪物离场后才开始大厅补位。记录胜负、经验发放、卡牌归属与去向为不同事件，方便环境牌替换其中一步。

## 6. 地下城大厅补位

大厅的标准可见阶层是 1、2、3。某张怪物离开后，较高阶层的牌依次向较低阶层移动，再从地下城牌堆顶补充阶层 3。需要记录每次 `HALL_ENTER` 和 `ENTER_RANK_1` 的实际原因；设置时就位于阶层 1 的怪物没有突破事件。

补牌翻出陷阱：立即结算陷阱，通常随后摧毁，继续补足大厅。补牌翻出宝藏：当前玩家立即获得并置于控制区，以后可按卡面摧毁发动效果；它不进弃牌堆。连续翻出这些卡时逐张处理，直到大厅只留下合法怪物或雷霆之石。循环需要“目标数量已完成”或“无牌可继续翻”之类的明确终止条件，不能以某轮没有命中目标就过早结束；这是 `TS-0689`、`TS-0693` 测试场景已确认的边界。

进入阶层 1 的怪物触发一次突破，随后不因为持续停留而反复触发。守护者到达阶层 1 时移至阶层 0 并补满大厅；阶层 0 可以有多名守护者。其持续效果影响所有玩家，阶层 0 攻击无光照惩罚；守护者通常只在战斗中被击败后离场。有守护者在阶层 0 时不能取得雷霆之石，但不阻止雷霆之石到达阶层 1 后结束游戏。

## 7. 终局与计分

标准对局在雷霆之石到达阶层 1 时立即触发终局，当前 `Match` 从 `PLAYING` 进入 `SETTLING`。只有当前玩家**击败阶层 1 怪物**而直接使雷霆之石移入该阶层，且没有阶层 0 守护者阻止取得时，才取得这张雷霆之石；其他进入原因没有取得者。`TS-0199`“放逐仪式”等设置会改变雷霆之石与末日之心的终局条件，应作为独立规则覆盖。

已实现的场景覆盖：飞龙尖塔取得第一张雷霆之石后继续，取得第二张后结束；雷霆之石未被取得而进入阶层 1 时也结束。放逐仪式中取得雷霆之石不结束对局，无人取得的雷霆之石突破时放回地下城牌堆底部；击败末日之心或末日之心突破才结束。末日之心战斗使每张手牌雷霆之石获得**魔法攻击 +6**；其战斗败北效果仅淘汰攻击者，其余玩家继续，全员淘汰则无赢家。末日之心突破后不会移入阶层 0。上述时点和淘汰行为有 `test_scenario_engine.py` 的公开命令测试。

引擎在 `SETTLING` 阶段基于**同一个终局快照**为每位玩家合计其抽牌堆、手牌、弃牌堆和其他受其控制卡牌的胜利点。固定印刷值从卡牌目录取；印刷 `*` 的牌通过已编译的计分能力求值，不用空值或 0 代替。最高分获胜；同分时持有雷霆之石的玩家优先，否则同分者共享胜利。确认终局后不再执行普通回合末抽牌。引擎返回结果；联机层保存并发布结果后更新房间状态，详见[交接契约](00-engine-boundary.md)。

## 8. 必要测试片段

- 阶层 2、光照 1、无其他修正时，攻击因黑暗减少 2；阶层 0 守护者没有该惩罚。
- 准备阶段摧毁应急干粮后，该卡不能再提供力量；战斗效果摧毁的卡仍完成本次战斗。
- 英雄力量跌至 0 后恢复，回合末只摧毁一次；武器因力量不足脱落时其加成立即消失。
- 普通怪物失败退回底部；守护者失败留在原阶层；两者的战斗效果都能发生。
- 连续陷阱和宝藏补厅时按出现顺序结算，宝藏进入控制区，突破只在合法移动进入阶层 1 时发生。
- 雷霆之石因胜利补位与因其他原因补位分别验证取得权，并测试阶层 0 守护者阻止取得但不阻止终局。
