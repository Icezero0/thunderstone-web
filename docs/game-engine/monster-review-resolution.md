# Monster review resolution

## 审核依据

已应用用户于 2026-10-22 提供的 [原始记录](../../archive/reviews/monster-review-2026-10-22T07-55-15-436Z.json)，保留其 132 条记录和 7 条备注。全部 345 条怪物能力的符号决定保存在 [能力级审核记录](../../cards/reviews/monster-symbols.json)：36 条有战利品符号，309 条无符号。没有填写、仍待审核或尚未选择符号的词条按用户要求视为无符号；明确选了“有符号”的兽人旗手保留此结论，即使原审核状态仍为待审核。

原文与能力 ID 全部匹配。部分旧绑定指纹因之前的身份标签迁移而变化；本轮按稳定能力 ID、原文及明确符号选择应用，原始指纹保留在归档中。

## 生效范围修正

| 卡牌 | 修正 |
| --- | --- |
| 余烬 TS-0495 | 文字“光照 +1”仅在对抗它时持续生效；卡面光照数值 1 仍用于它作为手牌时的贡献，两者独立 |
| 莫提斯领主 TS-0566、黑暗化身 TS-0568、梦魇骑士 TS-0570、闪现犬 TS-0650 | 无符号的光照减益仅对抗该怪物时生效；持有它们的手牌不会产生这些文字减益，相邻大厅怪物也不产生它们的减益 |
| 迅尾 TS-0660 | 所有英雄力量 -1 改为对抗该怪物时的持续修正，影响装备合法性；持有它作为手牌不产生该修正 |
| 假酒保 TS-0528 | 全局购买限制仅在大厅生效，手牌中的假酒保不会限制玩家购买 |

无“战斗：”前缀的这些持续规则通过 `battle_aura` 等机制参与预览和攻击合法性计算；不等待触发能力才结算。负光照不再从怪物文字自动推断为手牌数值。CSV 与 SQLite 的已整理卡面数值保持适用。

## 实现与验证

后续用户确认的[通用重洗与持续检定约定](04-turn-flow.md#持续翻牌检定)已同步用于海德拉、酒馆殴斗、滚石陷阱和龙之颚。成功处理、洗牌均不重置已有的无进展记录，仅按发生变化的实例重新检定。该约定替代此前本清单对海德拉“抽牌堆耗尽直接停止”的处理。

- 正式修改位于 TypeScript 解释器、持续计算及 `cards/effects/`；生成脚本同步更新，不依赖临时运行覆盖表。
- 审核页显示原备注和处理说明，仅在绑定指纹与本轮落实记录一致时自动继承“已确认”；新的修改和未来的规则变化仍可重新审核。
- [专项测试](../../backend/tests/effects/test_monster_review.py)验证全部符号与手牌范围一致，以及实际卡牌的逐张弃牌、标签、免疫、购买限制和自身事件排除。
- TypeScript 测试同时验证 Node 和浏览器的新增 DSL 编译、免疫选取及恢复时重校验。原有逐卡契约保留，新增规则通过当前 TS 引擎验证，旧 Python 解释器不扩展新规则。
